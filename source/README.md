# 老年ICU认知每日测评

院内研究者指导的单次EMA网页，待验收版本 `1.0.0-rc.2`。患者记录仅保存在当前浏览器的IndexedDB，不发送到GitHub。正式使用前，研究者须在Xiaomi Pad 6 Pro的Edge中完成设备验收。

## 当前范围

三词学习与首次即时回忆 → 五项症状 → 三张Stroop卡 → 延迟回忆 → 12题符号搜索 → 核查与ZIP导出。MoCA、一般资料、通知、院外同步和统计分析不在此版范围内。

## 快速使用

1. 打开[测评网址](https://qinghuiying1.github.io/icu-cognition-ema/)，横放平板、调整音量、关闭自动锁屏，准备纸笔。
2. 点击“准备离线资源”，然后在“模拟测评”中走完流程。验收页可集中试听全部词语与提示。
3. 按[操作与验收说明](docs/操作与验收.md)完成断网重开、完整测评、导出转存核对，再保存本台平板的验收记录。
4. 正式采集沿用既有研究编号，选择实际观察日。首次EMA日期一经保存，不更改固定七日词表。
5. 每次完成后核查有效性，下载ZIP，确认可打开，再转存电脑。网页请求下载不代表已经备份。

## 开发与构建

Node24、pnpm11，依赖版本见package.json和pnpm-lock.yaml。

```powershell
pnpm install --frozen-lockfile
pnpm test
pnpm build
pnpm preview
```

安装后只修复指定SDK版本的题间间隔参数读取；不更改RT过滤或原始结果。构建先复制锁定的SDK资源，生成本地静态包和逐文件SHA-256离线清单。固定中文WAV已包含在源材料中，安装不连接任何云语音服务。

`dist`是可迁移的完整静态网页；只发布程序与材料，不发布导出的患者记录、研究Word或数据Excel。没有付费域名、后端或服务密钥。

## rc.2使用反馈修改

每页增加返回主页、返回上一步和跳过；已完成认知部分返回后只查看原成绩，症状回答可在当前模块返回修改。五项症状使用1～5整数档滑动条。屏幕旋转不结束任务，45秒截止与原始反应时继续运行。Stroop使用原图任务矩阵的无损裁剪显示，去掉嵌入式标题并扩大显示；原图、50项内容和固定音频保留。

跳过保存为缺失，方向变化作为信息事件保留。主动离开正在计时的任务会保留该次尝试，避免在主页后台计时生成成绩。原始JSON同时附卡片显示坐标/哈希清单；CSV仍为28列。
