## 2. Stroop 计时、循环与错误处理

本研究 W、C、CW 每卡各计时 45 秒。完成 50 项后返回该卡首项继续；返回首项一次记循环次数 1，首次阅读的循环次数为 0。计时结束时停止，正确数允许大于 50。研究者对错误给出简短提示，由患者纠正；同一次项目纠正成功只计一次，不能将错误回答和纠正回答重复加分。循环次数和纸上记录用于核查正确数，不由平台从速度推算。

操作规则借鉴 [ADNI Depression Project Procedures Manual（封面Version 1.1，April 6, 2015）](https://adni.loni.usc.edu/wp-content/uploads/2017/09/ADNI_D_Procedures_Manual_2.15.17.pdf)：

| 来源位置 | 支持的用途 | 拟引用位置 |
|---|---|---|
| PDF 物理第 141 页／正文第 140 页，Stroop Word 与 Color Trial | 45 秒施测；读完后返回开头；错误提示与纠正处理 | 正文 Stroop 任务施测说明、附件 5 Stroop 操作规则、平台操作说明 |
| PDF 物理第 142 页／正文第 141 页，Color-Word 与计分说明 | CW 操作与计分的上下文核查 | 同上；保留版本差异说明 |

该手册使用的材料版本与本研究中文四色、每卡 50 项的现用卡片不同。它支持借鉴施测操作，不能据此宣称现用中文电子卡片本身已获得直接信效度验证。项目负责者已核对官方全文相应页；本素材说明记录来源和页码，不增加虚构的测量性能数字。

统一生成参数：

- 本机引擎：`System.Speech.Synthesis.SpeechSynthesizer`。
- 声线：`Microsoft Huihui Desktop`，`zh-CN`，女声；全部文件同一声线。
- 语速：`Rate = 0`；合成音量：`Volume = 100`。
- 格式：22050 Hz、单声道、16 位 PCM WAV。
- 静音处理：以绝对样本值大于 8 为发音活动阈值（约 -72 dBFS），裁去较长的首尾静音，在活动两侧保留 120 毫秒；未压缩或加速发音。
- 音量处理：最终全文件 RMS 目标 -23 dBFS，峰值上限 -1 dBFS；实际指标和增益逐文件记录。
- 全部最终文件无削波、非空，并能由标准 WAV 读取器回读；12 词均小于 1 秒。

固定音频的技术格式通过不等于已完成发音和临床可听性确认。研究者须核对 12 词的读音、清晰度和停顿，并在实际平板上试听；现场选择合适的设备音量后保持一致。普通话微软声线为本机已有的 Microsoft Windows 组件，本项目不把它描述为开源声线，也不分发该语音引擎或声线文件。

## 4. 复现、核查和版本锁定
