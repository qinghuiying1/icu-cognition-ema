# 符号搜索 SDK 改编记录

本平台使用 M2C2 官方 `@m2c2kit/assessment-symbol-search`，锁定 0.8.35；Session 锁定 0.3.19。原始刺激生成、图形排列、首次触摸选择和本机反应时计时均保留 SDK 实现。

## 本研究显式配置

- 12 个正式试次，上方 3 对、下方 2 对；保留 24 个原始符号、诱饵比例 0.5、左右正确位置比例 0.5。
- 每次任务传入已保存在测评记录中的随机种子。同一记录重新加载不得生成新种子，也不得在中断后自动重做。
- 题间关闭滑动动画，静态等待 200 毫秒。首次选择结束当前试次，不显示对错反馈，不要求错后重答。
- 正确数、正确率及正确试次的中位反应时由本平台对原始试次计算。`scoring` 设为 `false`，不使用 SDK 的参与者反馈分或过滤后评分；不另设反应时过滤区间和正确率剔除阈值。
- 保留 SDK 的 400 × 800 图形坐标比例；任务使用全屏覆盖层，由 SDK 对浏览器窗口进行等比例缩放，不裁切、不改符号的相对位置。中文指导显示在画布旁边，SDK 画布内的英文提问和“or”隐藏，避免缺少中文字库造成方框乱码。SDK 自带说明和倒计时跳过，从 `chooseCardScene` 开始。

## 题间参数修复

实际安装的 0.8.35 执行文件定义参数 `interstimulus_interval_duration_ms`，但关闭动画时的 `Action.wait` 读取 `interstimulus_interval_ms`。根目录 `scripts/patch-symbol-search.mjs` 在依赖安装后将执行文件内该读取名称改为已定义名称；依赖升级前需重新核查。已检查安装后的执行文件，等待分支读取的是修复后的名称。该修复不改变刺激生成、试次数或计时算法。

`scripts/prepare-symbol-assets.mjs` 将指定版本的 SDK 图像、字体及 Core 0.3.37 的 CanvasKit 0.41.1 WASM 复制到同源 `assets/symbol-search`，记录每个文件的 SHA-256 并保留两项 SDK 的 LICENSE。适配器显式将 SDK 素材路径指向此目录，避免外部 CDN 或 Pages 子目录解析错误。

## 计时和数据含义

SDK 在任务场景的 `onAppear` 中记录真实 ISO 时间并启动 `rt`；下方卡片第一次 `onTapDown` 停止计时。导出直接保留 `response_time_duration_ms`，而不是用两个墙钟时间相减或总用时除以题数。试次编号沿用 SDK 的 0～11。

原始刺激 `card_configuration`、正确选项、实际选择、刺激出现和作答结束时间，以及 SDK 的完整试次记录均保存。逐题保存回调按顺序执行；结束回调等待全部保存完成。保存失败和技术中断应保留已经保存的资料并停止本次任务，不产生替代成绩。
