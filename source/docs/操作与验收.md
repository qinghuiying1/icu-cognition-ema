# 操作与平板验收

设备：Xiaomi Pad6 Pro；Edge；横屏；院内热点。版本1.0.0-rc.2，词语及原始材料materials-1，卡片显示title-free-1。当前正式启用前，以下项目均需研究者在目标设备实际核验。

## 一次完整测评

1. **准备**：打开固定网址，加载离线资源；调音量，关闭自动锁屏。准备纸笔。选择模拟或正式、原研究编号、观察日1～7及首次EMA日期。不填写姓名或电话。
2. **学习**：播放三词，患者屏幕不显示词语。研究者在口头回答结束时立刻点击“回答结束”，再转向研究者打开录入页并按纸上记录逐词勾选。第一次成绩保留。如需继续学习，最多6轮（含首次）；词组不变。
3. **症状**：按患者选择录入疼痛、疲劳、焦虑、抑郁情绪（现在）和睡眠受干扰（昨晚），1～5分。
4. **Stroop**：首次说明可查看四项示范。三张卡各45秒，逐行从左到右。每卡读完回到首项继续，纸上记录正确数和返回首项次数。首次阅读次数为0，纠正成功的同次项目只计一次。结束后再录入。尽量保持横屏；意外旋转后计时照常，转回横屏直接继续。切后台或锁屏仍会停止计时任务并保留数据。
5. **延迟**：从最后一轮即时口头回答结束起计时，达到3分钟才能播放回忆提示；超过5分钟填写原因。无提示自由回忆，逐词勾选。
6. **符号搜索**：说明后开始12题；只记录首次点选，不纠错重答。看上方三对，在下方两对中选择相同的一对。
7. **核查**：检查显示成绩，选择1有效、0无效、9待核查。无效填写原因。低分、错误或慢反应本身不会自动剔除；三项成绩不可计算或有技术中断的记录保留待核查/无效。
8. **导出**：生成ZIP，打开平板下载文件夹确认文件，解压后检查JSON与CSV，再转存电脑。JSON保留原始记录，CSV中的空白为缺失而非0。模拟ZIP带“模拟”前缀，JSON中mode=simulation，不能并入正式研究。

## 页面返回与跳过

- 返回主页前保存当前进度及录入草稿。当前页内返回主页后可点击“继续刚才的测评”；已开始的记忆任务需在同一次网页会话内继续。真正关闭或刷新网页仍需核查，不能恢复原来单调计时起点。
- 当前感受部分“返回上一步”回到上一条症状，可修改回答；返回已完成认知部分只查看原始评分，并可“返回当前进度”。首次即时成绩不被重测覆盖。
- 跳过症状时只跳过当前条目；Stroop只跳过当前卡；跳过其它认知部分则保留已取得数据并继续后续流程。缺失评分不填0，CSV的completed记0表示未完整完成全部部分。存在认知任务缺失的当次记录不能直接标为有效。
- 主动从正在计时的Stroop/符号任务返回主页或上一步时，结束当前尝试并在原始事件中保留内容。回到该任务准备页后由研究者决定是否重新开始，平台不会在后台继续计时或自动替换原始尝试。
- 屏幕方向变化不会清空记录、停止任务、暂停截止或重置反应时，原始事件记录变化时间。原图标题和白边已去除；矩阵的50项像素、排列和颜色不变。

## 本地记录与重复导入

同研究编号、同观察日的正式测评打开原记录，不自动再测；模拟测评允许多个不同sessionId。已中断的记录不自动重做。JSON保存历史版本；重复导出的同一个sessionId只能导入一次，以最新研究者核查为准。

本地副本绑定固定网址、Edge配置和设备。不要使用隐私浏览，不清理网站数据，不卸载浏览器；更换网址/浏览器不会自动迁移患者记录。逐次导出转存是主备份流程。

出现保存失败时留在当前页点击“重试保存”，不要关闭页面。资源未准备、音频未能播放或计时流程中断须保留记录、检查技术原因；平台不会把总用时换算为符号搜索RT。
