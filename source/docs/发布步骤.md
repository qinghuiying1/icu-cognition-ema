# GitHub Pages发布

仓库已按main分支的docs目录发布；以下首次设置步骤供迁移或复现使用。账号操作由研究者完成，文件准备由本项目提供。只上传平台程序和公开材料；不要上传患者ZIP、数据Excel或研究Word。

## 账号操作

1. 登录GitHub，创建公开仓库 `icu-cognition-ema`，勾选Add README初始化。已存在就沿用，不重复创建。
2. 将完整源代码和已构建网页上传仓库。发布包内 `site` 是完整静态文件，可作为仓库 `docs` 文件夹；必须保留 `.nojekyll`、`sw.js`、`offline-manifest.json` 和所有资源，不能仅上传index.html。
3. 进入仓库 Settings → Pages → Deploy from a branch，选择main、`/docs`，Save。
4. 等GitHub显示实际Visit site链接，打开核查。对当前账号拟用地址为 `https://qinghuiying1.github.io/icu-cognition-ema/`，未成功发布前不把该地址当可用网址。
5. 平板Edge打开实际发布网址，按操作与验收说明做完整实机核验。

也可用GitHub Actions构建部署，首版采用预构建的docs静态目录以减少账号设置。代码内没有GitHub上传接口，浏览器记录始终留本地。

## 更新

正式采集前锁定已验收版本。更新时先导出当前记录，保留源代码、锁文件、静态包和材料哈希，修改版本号，再整体发布新包。测评中不激活新版本；如页面提示“新版本等待启用”，先导出并关闭所有测评页，重开后重新验收。

rc.2升级后页面底部显示1.0.0-rc.2。无需清理网站数据或重新填写研究编号；已有IndexedDB记录及七日词表保留。旧版页面若仍缓存显示，先联网点击“准备离线资源”，待新版本安装提示后关闭所有测评标签页，再重新打开；不要通过清空网站数据来更新。

公开仓库的GitHub Pages可在GitHub Free使用；该平台无付费域名、云后台或语音服务。外部政策长期变化不由本项目保证。
