# 老年ICU认知电子测评平台

院内研究者指导的单次EMA平台，版本1.0.0-rc.2。电脑技术核查已完成；更新后的Xiaomi Pad 6 Pro与Edge实机验收待研究者完成，验收前使用模拟模式。

- docs/：预构建的完整静态网页，含卡片、固定普通话音频、符号搜索资源及离线缓存。
- source/：可迁移的完整源码、锁文件、测评材料、操作说明及技术核查记录。
- 患者记录仅存当前设备浏览器，由研究者导出ZIP并转存电脑；本仓库不接收患者数据。

流程：三词学习与即时回忆 → 五项症状 → Stroop → 三词延迟回忆 → 12题符号搜索 → 核对导出。

## 使用

[打开测评平台](https://qinghuiying1.github.io/icu-cognition-ema/)。rc.2加入页面导航、1～5分滑动条、旋转后直接继续及去标题放大的Stroop矩阵。计时与原始反应时不因旋转暂停或重置，首次即时成绩保持不变，跳过评分保留缺失。电脑Edge完整流程、横竖切换、导出和离线重开已通过。首次联网加载资源，完成平板验收后再采集正式资料。

升级时先关闭所有旧的测评标签页，再重开本网址；底部应显示1.0.0-rc.2。保留浏览器网站数据，已有本地记录不因更新删除。
